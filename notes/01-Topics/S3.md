
Amazon S3 is an object storage service.

## Storage Classes

- **S3 Standard** → Frequent access, Multi-AZ
- **S3 Intelligent-Tiering** → Unknown/changing access pattern
- **S3 Standard-IA** → Rare access, Multi-AZ resilient
- **S3 One Zone-IA** → Rare access, recreatable data, One AZ
- **S3 Glacier Flexible Retrieval** → Archive, retrieval from minutes to hours
- **S3 Glacier Deep Archive** → Long-term archive, lowest-cost archive, retrieval in hours

💡 Unknown access pattern → Intelligent-Tiering
💡 Rare + recreatable → One Zone-IA
💡 Rare + Multi-AZ → Standard-IA
💡 Long-term archive → Deep Archive


## Versioning

Use Versioning to recover objects that were accidentally deleted or overwritten.

When you delete an object without specifying a version ID, S3 creates a **delete marker**.

Previous versions are still available.

💡 Accidental delete/overwrite → Versioning


## CRR — Cross-Region Replication

Replicates objects to a bucket in another AWS Region.

*Versioning* MUST be enabled on:
- Source bucket
- Destination bucket


## Existing Object Replication

Replication rules normally apply to new objects.

For existing objects use:

**S3 Batch Replication**


## S3 Object Lock

Protects objects from deletion or modification using WORM.

### Compliance Mode
Cannot be deleted or overwritten during the retention period, even by root.

### Governance Mode
Users with special permissions can bypass the retention settings.

💡 Strict regulatory requirement → Compliance Mode


## Private Content with CloudFront

For globally distributed private S3 content:

**User → CloudFront → OAC → Private S3 Bucket**

- CloudFront → global distribution / low latency
- OAC → allows CloudFront to access the private S3 origin

💡 Private S3 + CloudFront → OAC


## S3 Presigned URL

Provides temporary access to a specific S3 object.

💡 Temporary access → Presigned URL


## S3 Transfer Acceleration

Accelerates long-distance transfers between clients and an S3 bucket.

💡 Global users uploading large files → Transfer Acceleration

⚠️ Transfer Acceleration ≠ Cross-Region Replication


## Multipart Upload

Splits a large file into multiple parts that can be uploaded independently.

Useful for:
- Large files
- Unreliable connections
- Parallel uploads
- Resume failed uploads

💡 Huge file → Multipart Upload
